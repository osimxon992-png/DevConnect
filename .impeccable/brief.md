Scope: whole DevConnect web app (all routes, shared shell). Mode: Operate.
Audience/job: working developers worldwide; scan feed, answer questions, recruit/join projects, chat, browse jobs.
Constraint: no gradients, no purple/violet, no glow; must read as human-made. Content is real DB data only.

## Direction contract
THESIS: The app is a corridor noticeboard in a CS department: every post is a sheet of paper on the wall, every project, question and job is a flyer on coloured copy paper. Refuses the dark-glass purple dashboard and the grey-card-with-blue-button community template.
OWN-WORLD: Solar yellow #FFD21F nav rail; hallway grey #E6E8E1 ground; white paper sheets with no border and a hairline paper shadow; photocopy ink #111 plus one pencil grey #5A5B55; Astrobright fields by content type: Projects pink #F4669F, Questions blue #2E9BD6, Jobs green #5DBB63, Groups orange #FF8C3A. Archivo only, rank by width (62–100) and weight; JetBrains Mono for code only. Zero radius everywhere. State as marks in fixed cells: hollow open, filled solved.
STORY: A developer sees what people are building and asking, recognises flyers by colour at a glance, tears a role tab to ask to join, and answers questions.
FIRST VIEWPORT: Left 248px yellow rail with condensed uppercase DEVCONNECT wordmark, nav as plain rows, active row reversed black. Centre: search bar, black-underlined tabs, white post sheets with black code blocks. Right: pink project flyer ending in a perforated row of vertical role tabs, then blue question flyers with status marks.
FORM: Corridor Noticeboard, candidate 5 of 7 (CS hallway board); seed key 53c91469. Signature move: tear-off role tabs on project flyers; a taken role is a missing tab, an open role starts the join request with that role.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
